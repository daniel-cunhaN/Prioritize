# Objetivo do projeto
O objetivo do projeto é fazer uma lista de desejos centralizada. O usuário deve conseguir utilizar a função compartilhar link dentro de outros aplicativos, levando à esse aplicativo, em um modal em que herde:
-Link;
-Imagem do produto;
-Título do produto.

No mesmo modal, o usuário deverá classificar o produto em importância, utilizando uma escala de "Baixa, Média, e Alta".

O produto será armazenado em uma tabela estilo kanban, facilitando a visualização dos produtos e suas classificações para o usuário.
