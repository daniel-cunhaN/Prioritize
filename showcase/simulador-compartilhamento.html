2. Botão de Favoritos do Navegador ("Bookmarklet")

EFEITO WOW NO PROJETOR

Arraste o botão abaixo para a Barra de Favoritos do seu navegador (Chrome/Edge/Brave). Quando você estiver em qualquer página de produto da internet, basta clicar no favorito para enviar o produto para o Prioritize!

★ Compartilhar no Prioritize Dica: Pressione Ctrl + Shift + B para exibir a barra de favoritos e arraste o botão acima.

4. Apresentação no Celular / Emulador Android (Deep Link)

TERMINAL ADB / EXPO

Se preferir projetar o emulador Android ou celular conectado via USB:

npx uri-scheme open "prioritize://share?url=https://www.amazon.com.br/dp/8550801488" --android

Ou via ADB nativo:

adb shell am start -a android.intent.action.VIEW -d "prioritize://share?url=https://www.amazon.com.br/dp/8550801488"
