# Prioritize — Lista de Desejos Centralizada

Aplicação fullstack com backend em **Node.js (Express)** e frontend em **React Native (Expo)**.

---

## 🚀 Como Executar o Projeto

### 1. Instalar as Dependências

Na raiz do projeto, instale as dependências do backend e do frontend:

```bash
# Setup do Backend (Node.js)
cd backend
npm install
cd ..

# Setup do Frontend (Expo)
cd frontend
npm install
cd ..
```

---

### 2. Iniciar a Aplicação

Você pode iniciar o projeto de duas formas:

#### Opção A: Via inicializador unificado (Windows)
Dê um duplo clique ou execute no terminal:
```cmd
start.bat
```

#### Opção B: Via Node.js (Multiplataforma)
Na raiz do projeto:
```bash
node start.js
# ou
npm run dev
```

---

### 3. Rodar Testes do Backend (TDD)

O backend possui suíte de testes com cobertura para autenticação, banco de dados SQLite, scraping de metadados e rotas:

```bash
cd backend
npm test
```
